# Everything's Made to Be Broken
## (Take Comfort In Your Friends) 

Search for a song, watch several simultaneous YouTube covers of that song. Everything _is_ made to be broken. You _should_ take comfort in your friends. Man, I loved YouTube.

1. Install Node 24.22.1 or newer (`nvm use` reads `.nvmrc`)
2. `cp .env.example .env` and paste your YouTube Data API v3 key after `YOUTUBE_API_KEY=`
3. `npm install`
4. `npm start` (or `npm run dev` to restart on file changes)
5. After editing `assets/sass/style.scss`, run `npm run build:css`
